# Final Assessment - JavaScript Fundamental

Proyek ini berisi penyelesaian tugas akhir (*final assessment*) untuk kelas JavaScript. Repositori ini mencakup latihan wajib dan opsional yang mencakup berbagai konsep dasar JavaScript, mulai dari gaya penulisan kode, pengujian (*unit testing*), pemograman berorientasi objek (OOP), fungsi rekursif, hingga skenario penggunaan di dunia nyata.

---

## 📁 Struktur Proyek

```text
.
├── 01-writing-comments/          # Penulisan komentar pada JavaScript
├── 02-code-style/                # Pengrapian dan perbaikan gaya kode (linting/formatting)
├── 03-writing-test/              # Pembuatan unit test dasar
├── optional-04-oop/              # [Opsional] Pemrograman Berbasis Objek (OOP)
├── optional-05-recursive/        # [Opsional] Penerapan fungsi rekursif
├── optional-06-full-coverage-testing/ # [Opsional] Pengujian dengan cakupan penuh (100% coverage)
└── optional-07-real-world-scenario/   # [Opsional] Studi kasus skenario aplikasi nyata
